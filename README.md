唯时代尔 v0.9

俯视角像素射击 × 爬塔 Roguelike。一局共 15 层，每层打完回到中间地图补给与决策；第 5、10、15 层是 BOSS 战，第 15 层是三波终局演出。

- 引擎：Godot 4.6.1（纯 GDScript，无外部插件）
- 平台：Windows（单文件 exe）/ Web（浏览器直接玩）
- 玩法：随机场地 + 随机关卡节点 + 局内成长，死一次从第 1 层重来

【怎么玩】

【操作】

| 按键 | 作用 |
|---|---|
| W / A / S / D | 移动（八方向） |
| 方向键 ↑ ↓ ← → | 八方向射击，可同时按两个键斜向开火；按住连续射击 |
| E | 交互：对话、商店购买、确认、开关房间门（按住 3 秒） |
| T | 切换队友状态（周围保护 / 自主攻击），所有队友一起切 |
| F | 守护关建造模式开关（摆箱子、铺岩浆） |
| ESC | 暂停（继续游戏 / 回到主界面），暂停时冻结整局 |
| F1 | 调试面板（仅调试版）：改数值、雇佣队友、调试关卡、进入下一层 |

【一局怎么走】

1. 主界面「开始游戏」进入中间地图；有存档时下面会多一个「继续游戏」
2. 中间地图有三个位置，BOSS 层固定是「商店 - BOSS - 商店」，其它层从普通关 / 精英关 / 守护关 / 推车关 / 迷宫关 / 商店里随机（保底至少一个普通关）
3. 打完一层回中间地图补给，再进下一层；第 5 层、第 10 层、第 15 层固定 BOSS 关
4. 第 15 层打完三波并清空场上敌人即通关，整局结算回标题

【核心规则】

- 玩家基础 3 点生命，受击后 1.5 秒无敌（闪烁期间不掉血）；敌人贴住你才造成伤害，同一只敌人 0.5 秒结算一次
- 场地最外圈是一整圈坚固墙壁；红门开在场地内部，敌人从里面往外涌
- 岩浆地面：玩家和敌人踩上去都会烧，连续站满 1 秒扣 1 点血，跨岩浆格继续计时，离开才清零
- 商店：射速 / 伤害是「每个商店各限购一次」（BOSS 层两个商店就能各买一次），涨价全局累计
- 中途退出会从存档继续：每次进中间地图、每次买东西都会自动存一次，通关或失败自动删档

【内容】

【六种关卡】

- 普通关：清空几波敌人；精英关：击杀数量 + 撑满限时，两条都要达成
- 守护关：120 秒内守住场地中心 5 点生命的守护对象，开局可以先进建造模式摆箱子 / 铺岩浆
- 推车关：把箱子沿警戒线推到终点，路上有房间（开门清怪拿奖励）和敌人阻挡
- 迷宫关：走出迷宫即通关，敌人有「正面装甲」——正面只吃 20% 伤害（不足 1 点会弹 MISS），背面吃 120%
- BOSS 关：第 5 层单 BOSS，第 10 层原 BOSS + 两只紫 BOSS，第 15 层三波终局

【敌人】

| 敌人 | 特点 |
|---|---|
| 基础虫 / 快速虫 / 硬壳虫 | 血量与速度各不相同，都是贴身接触伤害 |
| 自爆虫 | 死亡时爆炸，会伤到玩家、队友，也会炸到 BOSS；免疫岩浆地板伤害 |
| 持枪敌人 | 远程，锁定目标后隔几秒开一枪，子弹不能穿墙；第 5 层之后进刷怪池 |

【三种 BOSS】

- 普通 BOSS：三阶段（66% / 33% 切换），技能是抛小怪、抛自爆怪、免伤冲撞；半血锁血 10 秒
- 紫色 BOSS：一个家族共用一份血池，血池到 75% / 50% / 25% 各分裂一个分身，另有瞬移与加速；家族全灭才一起倒下
- 岩浆 BOSS：丢自爆兵（落地砸 3×3 岩浆）、跳砸（蓄力 1 秒 + 腾空 1 秒，砸 5×5 岩浆）；半血钻地 10 秒，
  期间完全静默并从自己砸出的岩浆里爬出 20 只强化自爆兵（血量 / 移速各 +50%）
- BOSS 血量按层乘倍率：第 5 层 ×1（150）、第 10 层 ×2（300）、第 15 层 ×3（450）；岩浆 BOSS 再 ×1.2（180 / 360 / 540），紫色家族血池 = 每只本体各贡献一份

【成长】

- 局内金币来自击杀与掉落，在商店买：生命上限、恢复血量、子弹伤害、射速、雇佣队友
- 道具分红心与 BUFF 两类：回血、射速、移速、浮游炮（带弹幕形态变化），BUFF 有持续时间
- 队友最多 3 名，每人 3 点生命、可在队伍里存在 3 层（血量跨层保留），被打死即离队
